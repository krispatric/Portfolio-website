# PropertySuite AI Property Manager — Concept Prototype

An independent product concept by Kris Patrick exploring how PropertySuite could evolve from isolated AI features into a proactive AI operations layer across the property lifecycle.

## What the prototype demonstrates

- Proactive owner briefings driven by lifecycle and service context
- Mock AI conversations with contextual responses
- Maintenance triage and structured routing
- Human approval for consequential actions
- A bounded tool/action architecture rather than an open-ended chatbot
- Responsive, dependency-free static implementation suitable for GitHub Pages

## Important

This is an independent concept prototype using fictional/simulated data and mock AI replies. It is not an official PropertySuite product and is not connected to PropertySuite systems.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

This project is intentionally static, so it can be deployed directly from the repository root with GitHub Pages.
